# Veltris — Website Brief & Planning System

> This document is the strict rulebook for generating any future client website concepts.
> It must be followed before ANY design work begins.

---

## 1. Required Inputs (Website Brief)

Before generating any website concept, the following must be collected:

| Field | Description |
|---|---|
| **Business Name** | The exact legal or trading name of the business. |
| **Offer** | What the business sells or provides, in plain language. |
| **Target Audience** | Who the customers are — age, location, income level, lifestyle. |
| **Primary Goal** | The single most important outcome the website should achieve. |
| **Brand Personality** | 3–5 adjectives that describe the brand tone (e.g. "warm, honest, local"). |
| **Main CTA** | The one action visitors should take (e.g. "Call to order", "Book a table"). |
| **Design References (Liked)** | URLs or screenshots of designs the client admires. |
| **Design References (Disliked)** | URLs or screenshots of designs the client wants to avoid. |

---

## 2. Strict "Avoid" Rules

The following patterns are **banned** from all Veltris concepts:

### Visual Patterns to Avoid
- Purple/blue SaaS gradients
- Glassmorphism cards with frosted blur
- Floating dashboard mockups
- Random glowing ambient blobs
- Generic 3-column feature grids
- Startup-style hero sections with stock photos
- Abstract geometric backgrounds with no meaning
- Overly complex animations that slow page load

### Copy & Language to Avoid
- Vague corporate filler text
- Buzzwords and meaningless phrases:
  - "unlock"
  - "supercharge"
  - "streamline"
  - "seamless"
  - "leverage"
  - "empower"
  - "next-generation"
  - "cutting-edge"
  - "revolutionize"
  - "game-changer"
- Generic taglines like "The future of X" or "Your all-in-one solution"
- Placeholder copy that could apply to any business

## 3. Strict "Create" Rules

Every Veltris concept **must** include:

### Visual Requirements
- A **distinct visual concept** tied to the business identity — not a template
- **Strong typography** with intentional font pairing (serif + sans-serif or display + body)
- **Purposeful spacing** — the layout must "inhale" with generous whitespace
- A **memorable hero section** that immediately communicates what the business does
- **Layout choices that fit the audience** — a cafe should feel warm, a barber should feel sharp
- **Real photography** where possible, never stock photos of smiling businesspeople
- **Color palettes derived from the brand**, not from trending design systems

### Copy Requirements
- **Specific, human copy** written for the actual customer
- Copy that a real person at the business would say out loud
- **Concrete details** — prices, hours, locations, names
- A **clear conversion path** with one primary CTA and at most one secondary

### Technical Requirements
- Fully **responsive** across all breakpoints (320px to 1440px+)
- **Fast** — no unnecessary JavaScript, optimized images, minimal dependencies
- **Clean** markup with semantic HTML
- **Conversion-focused** — every section serves a purpose toward the primary goal

## 4. Mandatory Pre-Build Workflow

Before building any website concept, the following process must be completed:

### Step 1: Generate 3 Creative Directions
Based on the brief, generate three distinct creative directions. Each direction must include:
- A one-line concept summary
- Proposed color palette (3–5 colors with hex codes)
- Typography pairing
- Hero section approach
- Layout structure overview
- Tone of copy

### Step 2: Evaluate Each Direction
Score each direction against:
- **Audience fit** — Does it feel right for the target customer?
- **Brand alignment** — Does it reflect the brand personality?
- **Memorability** — Would someone remember this site after seeing it once?
- **Conversion clarity** — Is the path to action obvious?
- **Uniqueness** — Could this concept belong to any other business?

### Step 3: Select the Strongest Direction
Choose the direction with the highest overall score. Document the reasoning.

### Step 4: Build from That Direction Only
Do not mix elements from multiple directions. Commit to the selected concept and execute it with precision.

---

## 5. Final Quality Checklist

Before delivering any concept, verify:

- [ ] The design does NOT look like a SaaS landing page
- [ ] The design does NOT look like a startup pitch page
- [ ] The design does NOT look like an AI tool marketing page
- [ ] The copy is specific to THIS business (not interchangeable)
- [ ] The hero section is memorable and unique
- [ ] There is exactly 1 primary CTA per page
- [ ] The site is fully responsive (tested at 320px, 375px, 390px, 430px, 768px, 1024px, 1440px)
- [ ] No horizontal scrolling on any viewport
- [ ] Page load is fast with no layout shift
- [ ] Typography feels intentional, not default
- [ ] Spacing feels generous, not cramped
- [ ] Colors are derived from the brand, not from a generic palette
